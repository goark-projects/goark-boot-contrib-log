# Goark Boot Contrib Log 0.0.1

[English](https://github.com/goark-projects/goark-boot-contrib-log/blob/v0.0.1/docs/releases/v0.0.1.md) | 中文

发布日期：2026 年 9 月 6 日

Goark Boot Contrib Log 0.0.1 是 Goark 应用的首个公开日志 Starter。它将 Boot
配置映射到 `goark.dev/log`，安装主 `*slog.Logger`，并负责日志生命周期。

精简版本历史见[变更日志](https://github.com/goark-projects/goark-boot-contrib-log/blob/v0.0.1/CHANGELOG.zh-CN.md#001---2026-09-07)。

## :star: 新功能

- 映射与 Spring Boot 4.1 兼容的日志级别、Group、Threshold、文件滚动、字符集和
  结构化格式。
- 从 Boot 配置生成 Console 和滚动文件输出。
- 提供运行时级别控制，并解析文件或 classpath 配置。
- 在应用和遥测关闭期间保持日志可用。

## :package: 安装

```bash
go get goark.dev/gbc-log@v0.0.1
```

要求 Go 1.26 或更高版本。本版本依赖 Goark Core 0.0.1、Goark Boot 0.0.1 和
goark-log 0.0.3。

## :white_check_mark: 验证

候选版本已在 Windows Go 1.26 和 Debian Linux Go 1.27 上通过测试、vet、race、
结构化输出检查和生命周期集成。
