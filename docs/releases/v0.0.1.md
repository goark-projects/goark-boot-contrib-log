# Goark Boot Contrib Log 0.0.1

English | [中文](https://github.com/goark-projects/goark-boot-contrib-log/blob/v0.0.1/docs/releases/v0.0.1.zh-CN.md)

Release date: September 6, 2026

Goark Boot Contrib Log 0.0.1 is the first public logging Starter for Goark
applications. It maps Boot configuration to `goark.dev/log`, installs the
primary `*slog.Logger`, and owns the logging lifecycle.

See the [changelog](https://github.com/goark-projects/goark-boot-contrib-log/blob/v0.0.1/CHANGELOG.md#001---2026-09-06)
for the concise version history.

## :star: New Features

- Map Spring Boot 4.1-compatible logging levels, groups, thresholds, file
  rotation, charsets, and structured formats.
- Configure console and rolling-file output from Boot configuration.
- Expose runtime level control and resolve file or classpath configuration.
- Keep logging available through application and telemetry shutdown.

## :package: Installation

```bash
go get goark.dev/gbc-log@v0.0.1
```

Go 1.26 or later is required. This release consumes Goark Core 0.0.1,
Goark Boot 0.0.1, and goark-log 0.0.3.

## :white_check_mark: Verification

The candidate passed tests, vet, race tests, structured output checks, and
lifecycle integration on Windows Go 1.26 and Debian Linux Go 1.27.
